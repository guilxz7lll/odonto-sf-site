# Site Odonto SF

Site institucional responsivo, feito em HTML, CSS e JavaScript puro. Não precisa instalar dependências nem compilar.

## Estrutura

- `index.html` — conteúdo, SEO básico, links de contato e mapa.
- `css/style.css` — identidade visual, componentes e responsividade.
- `js/script.js` — menu mobile e ano automático no rodapé.
- `assets/` — logotipo vetorial, favicon e fotografias recortadas da referência enviada.

## Visualizar localmente

Na pasta do projeto, execute:

```bash
python3 -m http.server 5500
```

Depois abra `http://localhost:5500` no navegador.

## Publicar na Vercel

1. Envie a pasta do projeto para um repositório GitHub.
2. Na Vercel, importe esse repositório.
3. Selecione **Other** como framework, deixe Build Command e Output Directory vazios e publique.
4. O arquivo de entrada é `index.html`, que está na raiz.

## Informações para confirmar antes da publicação

- Os horários completos não aparecem nos dados recebidos. Por isso, o site orienta o visitante a confirmar a agenda pelo WhatsApp, sem inventar dias ou horários.
- Confirme com a clínica se os serviços apresentados continuam disponíveis e se deseja acrescentar preços, convênios ou condições especiais.
- Confirme o uso das fotografias e a autorização de imagem das pessoas que aparecem nelas antes de publicar o site.
- O número de telefone/WhatsApp usado nos botões é (92) 98281-9090, conforme os dados fornecidos.

## Identidade visual

A interface segue o grafite/preto, branco e amarelo-dourado presentes na referência da marca. O amarelo mais vivo fica reservado aos botões de ação.
